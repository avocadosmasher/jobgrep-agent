## 맥락
**P0의 결승선.** 여기까지 되면 "제품이 실제로 작동함"이 증명되고, 이후 작업은 전부 품질 증강이 된다. 어느 시점에 시간이 끊겨도 데모가 가능해진다.

## 화면
- 입력: 회사 / 직무 / **지원 목표 시점(date)** / JD 본문 붙여넣기 textarea
- [분석 실행] 버튼
- 결과: 요약 + `st.download_button`으로 `.md` 다운로드

## 불변식
- **실행 로직을 함수로 분리해둘 것.** T12에서 이 구조를 HITL 재개 루프로 교체한다. `st.button` 안에 로직을 인라인으로 박으면 T12가 전면 재작성이 된다
- 아직 HITL 없음 — 단순 `invoke` 1회

## 완료 조건
`streamlit run app/main.py` → JD 붙여넣고 실행 → `.md` 다운로드 성공.

## 검증
수동 — 다운로드된 `.md` 파일 또는 스크린샷 첨부
