## 맥락
도구들을 LangGraph 노드로 감싸 하나의 그래프로 잇는다.
**HITL·수집·Faiss는 아직 없다** — 붙여넣은 JD 1건으로 끝까지 관통하는 것만 목표다.

전체 아키텍처는 "LangGraph가 골격, ReAct는 수집 노드 안에만"이다. 흐름이 실제로 고정되어 있고 중단점이 필요하므로 통제를 흐름에 건다. 수집 노드(T18)만 예외적으로 자율성을 갖는다.

## 그래프 (P0 범위)
```
START → ingest_pasted_jd → extract → decompose → verify
      → aggregate → build_brief → fill_slots → END
```

> `fill_slots`는 T06b(`tools/fill_slots.py`)가 신설한 단계다 — `build_brief`가 만든
> 골격(■)의 서술형 슬롯(◇)을 채운다. 경위는 DEVLOG D13·D19.

## 불변식
- 각 노드는 `(GraphState) -> dict` **부분 갱신**만 반환. 전체 상태 반환 금지
- **노드는 도구를 호출할 뿐 비즈니스 로직을 갖지 않는다** (로직은 `tools/`에)
- `verify`가 questions를 반환해도 P0에서는 무시하고 진행 (HITL은 T11)

## 완료 조건
