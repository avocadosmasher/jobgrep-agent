## 맥락
사용자가 실제로 받아가는 최종 산출물. `StrategyBrief` → `.md` 문자열.
**T15 카드 렌더러와 같은 객체를 읽으므로 내용이 갈라질 수 없다** — 이게 이중 렌더러 설계의 요점이다.

## 할 일
- `render_markdown(brief: StrategyBrief) -> str`
- `filename_for(brief: StrategyBrief) -> str`

## 출력 규격 (§11-4 골격 순서 그대로)
```
[메타 헤더]   대상 회사·선택 공고 / 남은 기간 / 소스 충족률 % / 미수집 목록 / 신뢰등급
[요약 판정]   3-state 집계(충족 N·인접 M·미충족 K) + 총평 한 줄
[트랙1 내세울것]
[트랙2 채울것]   priority 순
[트랙3 포기할것]
[컬처핏]      없으면 "미수집" 표기
[공백 고지]   판단 못 한 항목 + 이유
```

## 불변식
- **LLM 호출 없음** (순수 직렬화)
- 근거는 `<details>` 또는 하단 부록으로 평탄화 (본문이 텍스트 늪이 되지 않게)
- 파일명: `{회사}_{직무}_전략브리프_{YYYYMMDD}.md`
- 빈 트랙은 섹션을 없애지 말고 **"해당 없음"** 출력

## 완료 조건
픽스처 brief 렌더 시 7개 섹션 전부 존재, 빈 트랙 처리 확인.
