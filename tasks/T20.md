## 맥락 — 이 태스크는 선택이다
공식 채용 API는 **키 발급·승인이 통제 불가 요소**라 의도적으로 크리티컬 패스에서 제외되어 있다.
**미완이어도 제품은 완주해야 한다.**

착수 시점에 이미 P0~P2가 동작 중이므로 일정에 영향이 없다. 승인이 지연되면 **이 태스크를 `⛔`로 두고 다음 Phase로 진행**할 것.

## 현실 정보
- 원티드 — 3자용 공개 검색 API 사실상 부재
- 사람인·잡코리아 — 키 발급·승인 실무 필요
- 공공데이터포털(워크넷 채용정보) — 접근이 상대적으로 빠르나 대기업 자체 채용 커버리지 낮음

## 규칙
- 키 미발급/실패 시 **조용히 스킵**하고 T19의 다른 경로로 폴백
- API는 메타 + URL만 제공하는 경우가 많음 → **본문은 T16의 3층 폴백으로**

## 완료 조건
API 없이 실행해도 T19가 정상 동작함을 재확인(회귀 방지).
