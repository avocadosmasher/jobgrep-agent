## 맥락
매칭이 기준 단위로 쪼개져 있어(T05), 채점자가 "판정이 타당한가"라는 큰 질문 대신 **기준별 소판정이 맞는가**를 평가할 수 있다 → 평가자 간 일치도가 올라간다.

## 평가 차원 (5개, 3점 척도: 부적합/부분적합/적합)
| 차원 | 판정 대상 |
| --- | --- |
| 근거 타당성 | 근거가 주장을 실제로 뒷받침하는가 |
| 요구역량 정확성 | 환각·무관 항목이 섞이지 않았는가 |
| 매칭 판정 타당성 | 기준 분해와 3-state 집계가 타당한가 |
| 실행 가능성 | 학습 순서가 구체적이고 기간이 현실적인가 |
| 전략 타당성 | 트리아지가 남은 기간에 비추어 합리적인가 |

## 게이트 (점수 아님)
**컬처핏 안전선 위반은 다른 항목 만점이어도 실패 처리.**
(합격해도 본인이 불행해지는 "공략법"은 생성 자체가 금지)

## 불변식
- **사람이 매긴 20~30건과의 일치율을 먼저 검증한 뒤에만** 자동 채점을 신뢰
- **심사 모델 ≠ 생성 모델.** 같으면 자기 출력을 과대평가한다

## 완료 조건
