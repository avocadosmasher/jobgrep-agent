## 맥락
**이력서·경력기술서는 대부분 텍스트 레이어가 살아 있는 PDF/DOCX다.** OCR을 무조건 태우면 품질이 오히려 나빠진다. 그래서 OCR은 기본 경로가 아니라 fallback이다.

## 계층
```
1) 확장자 분기
   .docx      → 문서 파서로 직접 추출
   .pdf       → 텍스트 레이어 추출 시도 (pdfplumber / PyMuPDF)
   .png/.jpg  → 3)으로 직행

2) 품질 검사 (코드, 결정론적)
   문자 수 / 공백 비율 / 한글 포함 여부 → 임계 미달이면 스캔본으로 판단

3) OCR fallback → T22

4) 실패 시 → 추출 텍스트를 사용자에게 보여주고 직접 보정 (H4, T22)
```

## 불변식
- 품질 검사는 **LLM이 아니라 코드**로 (결정론적)
- 반환은 `(text, Confidence)` — 어느 경로로 얻었는지 신뢰도에 반영

## 완료 조건
텍스트 PDF는 OCR 없이 추출, 스캔 PDF는 OCR 경로로 분기됨.
