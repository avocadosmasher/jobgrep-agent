## 맥락
이후 모든 태스크의 검증 명령이 `uv run ...`으로 실행된다. 그 환경을 가장 먼저 세운다. T01의 검증(`uv run python -c "from contracts..."`)조차 이 태스크가 끝나야 돌아가므로 **T01보다 먼저**다.

## 할 일
```bash
uv init --package .            # pyproject.toml 생성 (또는 uv init)
uv venv                        # .venv 생성
uv add pydantic                # T01이 즉시 필요
uv add --dev pytest            # 테스트 러너
```
- `pyproject.toml`에 **pytest 마커 등록** (LLM 테스트 분리에 필수):
  ```toml
  [tool.pytest.ini_options]
  markers = ["llm: 실제 LLM API를 호출하는 테스트 (비용 발생)"]
  ```
- `.python-version`에 3.11+ 고정
- `.gitignore`에 `.venv/`, `.env`, `__pycache__/`, `*.faiss` 등
- `.env.example`에 `OPENAI_API_KEY=` (실제 `.env`는 커밋 금지)

## 의존성 관리 방침 (이후 전 태스크 공통)
- 런타임 의존성은 **미리 다 넣지 않는다.** 각 태스크가 필요할 때 `uv add <pkg>`로 추가한다
  (예: T04 `uv add openai`, T08 `uv add langgraph langchain`, T14 `uv add faiss-cpu`)
- `pyproject.toml` / `uv.lock` 변경은 **R2(소유 파일) 예외** — 어느 태스크든 `uv add` 가능.
  단 추가한 패키지·버전을 `DEVLOG.md`에 한 줄 남긴다

## 완료 조건
