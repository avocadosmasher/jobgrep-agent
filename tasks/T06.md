## 맥락
판정 결과를 3트랙으로 트리아지한다. 이 제품의 최종 가치("부족분 나열"이 아니라 "남은 기간에 어디부터 손댈지")가 여기서 만들어진다.

**골격(■)은 전부 코드가 결정**하고 LLM은 슬롯(◇: `body`, `summary_line`)만 채운다. 이 분리가 멱등성 주장의 근거다 — 구조와 계산은 멱등이고 자연어는 아니다.

## 트리아지 규칙 (■ 결정론)
```
트랙1 내세울것 : state=MET 이면서 my_level > required_level → is_strength=True
트랙2 채울것   : ADJACENT 우선, 그다음 UNMET 중 남은 기간 내 가능한 것
                 → priority 부여 (인접 항목이 상위 — 학습비용이 낮으므로)
트랙3 포기할것 : 소요 구간 > 남은 기간 인 UNMET
```

## 결측 처리 3분류 (반드시 구현)
| 상황 | 처리 |
| --- | --- |
| 트랙1이 빔 | **미달 항목을 강점으로 재라벨링 금지.** 고정 문구 + 트랙2 최우선 항목 인용 (새 판정이 아니라 기존 순위의 인용) |
| 트랙이 빔 | "해당 없음" 표기 (정상 상태) |
| evidence 없는 항목 | **카드 미생성** (라벨링하지 않는다) |

## 불변식
- 학습 순서는 **절대 시간이 아니라 상대 순위 + 구간(단기/중기/장기)** 으로만 표현 (개인차가 커서 절대 추정은 근거가 약함)
- `days_remaining`은 `target_date` 기준 코드 계산
- 같은 입력 → 같은 트랙 배정 (결정론 테스트로 증명)
