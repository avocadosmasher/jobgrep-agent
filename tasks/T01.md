## 맥락
이 프로젝트의 모든 모듈이 import할 인터페이스를 만든다. 이후 모든 태스크는 여기 정의된 타입만 보고 작업하므로 **이 파일이 곧 API 문서**다. 산문 명세는 해석 여지가 있어 표류하지만 import한 타입은 표류할 수 없다 — 그래서 계약을 코드로 둔다.

## 할 일
`docs/계약_초안.md`의 정의를 실제 파일로 옮긴다. **구현 로직은 넣지 않는다** — `tools.py`는 시그니처 + docstring만, 본문은 `...`.

## 불변식
- `tools.py`의 각 함수에 **입력·출력·불변식 docstring** 필수. 이게 이후 세션이 읽는 실질 API 문서다
- 모든 노드 규약: `def node(state: GraphState) -> dict` — **부분 상태 갱신 dict** 반환. 전체 상태 반환 금지
- enum 값은 초안 그대로 (한글 값 유지 — 브리프 렌더링에 그대로 쓰임)

## 완료 조건
- 모든 심볼 import 가능
- Pydantic 모델 인스턴스화·직렬화 가능
- `tools.py` 전 함수에 docstring 존재
