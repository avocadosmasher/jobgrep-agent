## 맥락
T07 markdown과 **같은 `StrategyBrief`를 읽는 두 번째 렌더러.** 단일 객체 → 두 경로 렌더링이므로 내용이 갈라질 수 없다.

**T14b가 먼저다.** `my_level`이 `None`인 채로 착수하면 아래 "내 레벨 vs 요구" 줄이 전부 "없음"으로 굳고, parity 테스트가 그 상태를 고정한 뒤 다시 열어야 한다. 경위는 DEVLOG D40.

## 규격
- 상단 배지 — 남은 기간 / 최소 요건 충족 여부
- 카드 = `역량명 / 중요도 / 3-state 배지 / 내 레벨 vs 요구 / 기준별 판정`
- **근거는 기본 접힘** (`st.expander`) — 펼치면 텍스트 늪이 된다
- 트랙별 섹션 구분

## 배선 (빠뜨리면 이 카드는 죽은 코드가 된다)
`app/main.py`가 T09 때 자기 파일 안에 임시로 만든 인라인 렌더링(`render_summary` ·
`render_tracks` · `render_gaps`)을 **`render/cards.py` 호출로 교체한다.** 안 그러면
`render/cards.py`를 아무도 부르지 않아 화면이 그대로고, 아래 불변식이 UI에서 성립하지
않는다. `render_markdown`을 쓰는 다운로드 버튼은 건드리지 않는다.

## 불변식
> **출력 항목 하나 = UI 카드 하나 = .md 섹션 하나 = 루브릭 평가 단위 하나.**
> 이 일치가 T27 평가를 가능하게 한다.

같은 brief를 T07과 렌더했을 때 **표시 항목 집합이 동일**(순서·형식만 다름).
