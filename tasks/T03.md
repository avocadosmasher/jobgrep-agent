## 맥락
매칭 파이프라인의 마지막 단계. **LLM을 절대 쓰지 않는 순수 규칙 함수**이며, 이 결정론성이 제품 신뢰도(멱등성) 주장의 근거다. 최종 등급은 LLM이 뱉는 숫자가 아니라 감사 가능한 소판정들의 산술이어야 한다.

## 구현 규칙
```
필수 기준 전부 충족       → MET(충족)
필수 기준의 절반 이상 충족 → ADJACENT(인접)
그 외                     → UNMET(미보유)

PARTIAL 은 0.5 로 계산
UNKNOWN 은 분모에서 제외
```

`ADJACENT` 상태가 이 설계의 핵심이다 — Docker 경험자에게 "K8s 미보유"는 부정확하며, "오케스트레이션만 얹으면 된다"가 진짜 유용한 정보다. 시간이 촉박할수록 인접 항목이 최우선 보완 대상이 된다.

## 불변식
- 순수 함수 — 부작용·IO·LLM 호출 없음
- **경계값은 모듈 상수로 분리** (설계도 §16 S6 미확정 — 추후 튜닝 대상)
- 모든 UNKNOWN이면 UNMET이 아니라 판정 불가로 취급할지 결정하고 docstring에 명시

## 완료 조건
픽스처 3종(all_met / half / mostly_unmet)에서 각각 MET / ADJACENT / UNMET 산출.
